# zibo_admin

Zibo yönetici uygulaması — tek yönetici hesabı, Zibo ile aynı Firebase projesi. Play'e YÜKLENMEZ;
imzalı APK telefona elle kurulur. Plan, kararlar ve adımlar: `../dijital_kanka/docs/admin_panel.md`.

Uygulama ikonu (Kral Zibo, turuncu zemin) — repo kökünden yeniden üretmek için:
`python tool/make_icon.py ../dijital_kanka/assets/images/zibo_king.webp android/app/src/main/res önizleme.png`
(`zibo_admin/` içinden çalıştır).
